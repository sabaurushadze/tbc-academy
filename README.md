# დავალება 4

შექმენით გვერდი შემდეგი ვიზუალური კომპონენტებით:

    
- სათაური “Profile Info”
- შესაყვანი ველი “Email”
- შესაყვანი ველი “Username”
- შესაყვანი ველი “First Name”
- შესაყვანი ველი “Last Name”
- შესაყვანი ველი “Age”
- ღილაკი “Save”
- ღილაკი “Clear”


შეგიძლიათ დაამატოთ სხვა ველები თქვენი ინიციატივით. “Save” ღილაკზე დაჭერისას უნდა
შემოწმდეს


- შევსებულია თუ არა ყველა ველი.
- “Username” ში შეყვანილი სიმბოლოების რაოდენობა არ უნდა იყოს 10-ზე ნაკლები.
- ვალიდურია თუ არა ელექტრონული ფოსტა
- “Age” უნდა იყოს მთელი დადებითი რიცხვი
- რომელიმე პირობის შეუსრულებლობის შემთხვევაში გამოტანეთ ეკრანზე შესაბამისი ტექსტური შეტყობინება.

“Clear” ღილაკზე დაჭერისას ველები უნდა გასუფთავდეს. აღნიშული ოპერაცია უნდა სრულდებოდეს
მხოლოდ იმ შემთხვევაში თუ მომხარებელმა ღილაკს დააჭირა ხანგრძლივად


ბონუსი :
"Save" ღილაკზე დაჭერისას სქრინზე უნდა გაქრეს ყველა ვიზუალური კომპონენტი (გარდა Profile
Info ) და გამოჩნდეს შემდეგი კომპონენტები

- ტექტსური მონაცემი “Email”
- ტექტსური მონაცემი “Username”
- ტექტსური მონაცემი “First Name” + “Last Name”
- ტექტსური მონაცემი “Age”
- "Again" ღილაკი. მასზე დაჭერისას კვლავ საწყის პოზიციაზე უნდა დაბრუნდეს
ვიზუალური კომპონენტები

აღნიშნული ტექსტური ვიზუალური კომპონენტები უნდა შეივსოს თავდაპირველად შეყვანილი

# დავალება 8-9

გვერდზე დაამატეთ შემდეგი ვიზუალური კომპონენტები:

- “First Name”, “Last Name”, “Age”, “Email” შესაყვანი ველები.
- ეკრანის უკანა ფონზე განათავსეთ სურათი. სურათის პიქსელები არ უნდა იყოსდარღვეული
- ოპერაციის საიდენტიფიკაციო ტექსტური კომპონენტი (Success/Error). ოპერაცია თუწარმატებულია ტექსტის ფერი უნდა იყოს “green”წინააღმდეგ შემთხვევაში “red”
- აქტიური მომხარებელების რაოდენობა
- წაშლილი მომხარებლების რაოდენობა
- “Add User” ღილაკი
- “Remove User” ღილაკი “Update User”

“Add User” ღილაკზე დაჭერის შემდეგ მომხმარებლის ინფორმაცია დაამატეთ კონტეინერში. Თუ მომხარებელი უკვე დამატებულია ეკრანზე გამოაჩინეთ შეტყობინება “User already exists” წინააღმდეგ შემთხვევაში “User added successfully” “Remove User” ღლაკზე დაჭერისას კონტეინერიდან წაშალეთ მსგავსი ინფორმაციის მქონე მომხარებელი და ეკრანზე გამოაჩინეთ “User deleted successfully” ,თუ მომხარებელი არ არსებობს ეკრანზე გამოიტანეთ შეტყობინება “User does not exits”.“Update User” ღილაკზე დაჭერისას უნდა ხდებოდეს მომხარებლის ინფორმაციის აპდეითი (ინდივიდუალურად უნდა მოიფიქროთ რა მექანიზმით იქნება მიზანშეწონილი აღნიშული ოპერაციის შესრულება).

დავალება გადააკეთეთ შემდეგნაირად

- Add User ფუნქციონალი გადაიტანეთ ცალკე გვერდზე სადაც შეავსებთ სათანადო მონაცემებს და “Add User” ღილაკზე დაჭერით დაბრუნდებით მთავარ გვერდზე და აჩვენებთ განახლებული იუზერების როაოდენობას.

- “Update User” ღილაკზე დაჭერით შეამოწმეთ არის თუ არა ცარიელი მომხმარებელბის სია. თუ ცარიელია გამოიტანეთ ეკრანზე შეაბამისი შეტყობინება წინააღმდეგ შემთხვევაში რენდომათ აიღეთ მომხმარებელი იუზერების სიიდან და გახსენით “Add User” სქრინი სადაც ველები ავტომატურად შევსებული იქნება(ელქტრინული ფოსტის ველი უნდა იყოს დადიზეიბლებული და მომხმარებელმა ვერ უნდა შეცვალოს), გვერდზე ნაცვალდ “Add USer” ღილაკისა უნდა იყის “Update User”. ღილაკზე დაჭერით უნდა დაბრუნდეთ მთვარ გვერდზე და შესაბამისი მომხარებლის ინფორმაცია უნდა დააპდეითოთ. ამავე გვერდზე როდესაც გვერდი იმყოფება აპდეითის რეჟიმში გამოაჩინეთ ღილაკი “Remove User” ღილაკი. მასზე დაჭერისას ისევ მთავარ გვერდზე უნდა დაბრუნდეთ და აჩვენოთ შეაბამისი მომხარებლების რაოდენობა (არც ეს დაგავიწყდეთ -> წაშლილი მომხარებლების რაოდენობა)

- მთავარ გვერდზე დაბრუნებისას არ დაგავიწყდეთ აჩვენოთ შეტყობინება შერულებული ოპერაციის შესაბამისად.

- გაითვალისწინეთ -> მომხარებლის ინფორმაციის გადასატანად ერთი გვერდიდან მეორეზე გამოიყენეთ მოდელ კლასი. თუ რაიმე სხვა დამხამრე არგუმენტი დაგჭირდებათ არ ხართ შეზღუდულები
